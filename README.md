# candle-board（A股版）

基于《日本蜡烛图技术》的 **A股** 交易决策辅助看板。形态初筛 + 六层过滤 + T+1 人工终审。

**本工具为技术分析学习辅助，不构成任何投资建议。股市有风险，投资需谨慎。**

## Phase 1 已适配

- 仅 A股 / 指数 / ETF（无美股、无加密）
- 周期：日 / 周 / 60分
- 涨跌停、一字板、异常跳空过滤；图上标注涨跌停虚线
- 六层过滤：位置 · 个股+上证 · 形态质量 · RSI/KDJ/MACD · 量比 · **T+1确认**
- 顶部大盘状态灯（上证/深证/创业板）
- 交易计划：整百股、建议入场日、最早卖出日（T+1）
- 看跌信号仅作「减仓/不买入」参考，不生成做空计划

## 本地运行

```bash
yarn install
yarn dev
```

打开 http://localhost:3000

行情：新浪 / 腾讯公开接口（前复权日线等）。北向资金、换手率、板块热力等属 Phase 2。
