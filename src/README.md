# candle-board

基于《日本蜡烛图教程》的**交易决策辅助看板**（非自动交易机器人）。

系统负责形态初筛与六层验证，人负责终审与执行。界面强制检查清单，不可跳过确认。

> 辅助工具，非投资建议。

## Phase 1 MVP

- 多品种 K 线（Binance 加密 + Yahoo 股指/黄金/外汇），周期 1H / 4H / D / W
- 成交量 + MA20/50，RSI / Stochastic / MACD，ATR(14)
- 主周期切换时显示大周期趋势箭头
- 单/双/三 K、持续形态、Spring / Upthrust（需你画的支撑阻力）
- 信号分级 S / A / B + 形态质量 1–5
- 半自动结构：水平线磁吸、趋势线、斐波那契、均线、测试计数、Spring 锚点
- 六层过滤器交通灯
- 交易计划：止损（极值 ± 1×ATR）、三级止盈、仓位、盈亏比 &lt; 1.5 拦截
- 检查清单导出（打印/PDF）

## 本地运行

```bash
yarn install
yarn dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 数据

- 加密：Binance 公开 K 线
- 股票/ETF/外汇：Yahoo Finance
- 源失败时自动回退演示数据

## 原则

形态识别只做初筛。未画结构线时，位置层为红灯属预期行为。
